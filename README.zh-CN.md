# 一键记事（quick-catch）

一个 [思源笔记](https://github.com/siyuan-note/siyuan) 插件，只提供一项功能：一键记事。

## 功能特性

- 在思源笔记运行在后台（未退出）时，在任何软件中按设置好的快捷键即可唤出悬浮记事小面板
- 按 `Enter` 直接提交（`Shift+Enter` 换行），记完**直接**在默认笔记本中生成一篇以时间戳为标题的文档（不创建中间文件夹）；不会打开新文档，不打断当前操作
- 快捷键无默认值，需在「设置 → 快捷键 → 插件」中自行设置；顶栏按钮点击后打开设置面板，可设定默认笔记本
