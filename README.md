# One-Tap Note (quick-catch)

A [SiYuan](https://github.com/siyuan-note/siyuan) plugin that provides only one feature: one-tap note taking.

## Features

- Press the configured hotkey anywhere (even when SiYuan runs in the background, not exited) to summon a small floating input panel
- Press `Enter` to submit, `Shift+Enter` for a newline; the note is saved directly into your default notebook as a document named by timestamp (no intermediate folder is created). The note is not opened, so your current work is not interrupted
- The hotkey has no default: set it in `Settings → Shortcuts → Plugins`; the top bar button opens the settings panel to set the default notebook
